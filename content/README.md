# Контент сайта

Весь меняющийся контент лежит здесь в JSON-файлах. Сборка проверяет каждый файл по схеме
(`app/shared/content/schema.ts`): опечатка, неизвестное поле или несуществующая категория
останавливают сборку и сообщают, в каком файле проблема. Публикация происходит автоматически
после `git push` в ветку `main`.

| Что                       | Где                    | Примечание                                                         |
| ------------------------- | ---------------------- | ------------------------------------------------------------------ |
| Контакты, Telegram, адрес | `settings.json`        | Пока `salesTelegram` пуст, кнопки «Обсудить в Telegram» отключены. |
| Категории каталога        | `categories.json`      | Ровно те категории, которые видны на главной и в каталоге.         |
| Предметы каталога         | `products/<slug>.json` | Имя файла — публичный адрес и идентификатор предмета в избранном.  |
| Статьи Journal            | `articles/<slug>.json` | Интервью с другими изданиями уже встроены и здесь не нужны.        |

Тексты задаются на трёх языках: `{ "ru": "…", "uz": "…", "en": "…" }`. Русский обязателен,
пустые `uz` и `en` показываются по-русски.

## Как добавить предмет

1. Положите фотографии в `public/products/` (например, `public/products/duality-cup.jpg`).
2. Скопируйте `examples/product.json` в `products/duality-cup.json` и заполните поля.
3. Выполните `npm run check`, затем сделайте commit и push.

Цена `null` означает «по запросу». Если у предмета есть `variants`, посетитель обязан выбрать вариант,
прежде чем обращение будет готово. Поле `sourceArtwork` связывает предмет с картиной из
`app/shared/content/artworks.ts` и показывает блок «Начало образа». Не указывайте его, пока связь не подтверждена.

## Как добавить статью

Скопируйте `examples/article.json` в `articles/<slug>.json`. Темы: `meanings`, `culture`, `learning`,
`interviews`, `events`. Абзацы в `body` разделяйте пустой строкой.

Папка `examples/` в сборку не попадает.
